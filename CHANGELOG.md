# Changelog

All notable changes to Niaromi are documented in this file.

## [1.0.0] - 2026-11-19

### Highlights
- **Editorial Bookshelf UI**: Complete redesign inspired by minimalist Didone typography, warm ivory palette (`#FFFDF4`), and translucent floating acrylic shelves.
- **eBook & EPUB Support**: Added native parsing, pagination, chapter index, and drop-cap reader for `.epub` eBooks alongside manga formats.
- **Unified Cross-Extension Explore Feed**: Real-time aggregation of latest releases across installed extensions with automatic title deduplication and preferred source priority.
- **Cloud Backup & Restore**: Automated Google Drive backup and recovery of library state, reading progress, and preferences.
- **Batch Extension Migration**: One-click intelligent migration of manga titles between extensions.
- **Diagnostics & Error Handling**: Clear, actionable error messages for network timeouts, chapter availability, and extension statuses.
- **Storage Auto-Resolution**: Automatically detects or creates standard storage folders (`Documents/Niaromi`) without manual directory pickers.
