# Niaromi

Niaromi is an Android app for reading manga, comics, and EPUB books. It keeps your library and reading progress together and supports optional backups to Google Drive.

## Install

Get the universal APK from [GitHub Releases](https://github.com/workwithshabd/niaromi/releases). Niaromi requires Android 8.0 or later.

## Build

Open the project in Android Studio with JDK 21 or newer. Run `./gradlew :app:assembleDebug` to build a debug APK and `./gradlew check` to run the project checks.
