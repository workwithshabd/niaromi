# Contributing to Niaromi

Thank you for your interest in contributing to Niaromi!

## Getting Started

1. Fork or clone the repository:
   ```bash
   git clone https://github.com/workwithshabd/niaromi.git
   ```
2. Open the project in Android Studio (Ladybug or newer recommended).
3. Ensure you have JDK 21 configured.

## Code Standards

- **Kotlin & Jetpack Compose**: Follow standard Kotlin conventions and Compose guidelines.
- **Formatting**: Run `./gradlew spotlessApply` before submitting your changes.
- **Verification**: Ensure all checks pass by running `./gradlew check`.

## Reporting Issues

If you find a bug or have a suggestion, feel free to open an issue on GitHub:
https://github.com/workwithshabd/niaromi/issues
